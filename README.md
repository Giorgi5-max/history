# ისტორია · VII კლასი

ისტორიის სასწავლო ვებაპის კოდი. მოსწავლის ხედში გაერთიანებულია გაკვეთილის ტექსტი, ავტომატური რეზიუმე, მოსმენა, ვიდეო და 20-კითხვიანი ქვიზი. მასწავლებლის პანელი პარაგრაფზე ვიდეოს, აუდიოსა და პოდკასტის ატვირთვას უზრუნველყოფს.

[გახსენით აპი](https://istoria-vii-class.giorgi-gorjeladze-1.chatgpt.site)

## ადგილობრივი გაშვება

საჭიროა Node.js 22 ან უფრო ახალი ვერსია და გაკვეთილების მონაცემები. ამავე აპის გამოქვეყნებულ პირად ვერსიაში 38 პარაგრაფია. ადგილობრივი გაშვებისთვის მოათავსეთ თქვენი მონაცემები `content/ge.txt` და `content/world.txt` ფაილებში. სათაურები და პარაგრაფების იდენტიფიკატორები განსაზღვრულია `public/catalog.js`-ში.

ფორმატის მაგალითი:

```text
# ge-1
## ქვეთავის სათაური
ქვეთავის სასწავლო ტექსტი.
- შეკითხვა? | სწორი პასუხი | მცდარი პასუხი 1 | მცდარი პასუხი 2 | მცდარი პასუხი 3
```

თითო პარაგრაფზე გამოიყენეთ ოთხი ქვეთავი და თითო ქვეთავზე ხუთი შეკითხვა. თუ მცდარი პასუხები გამოტოვებულია, აპი იმავე ქვეთავის სხვა პასუხებს არჩევს.

შექმენით `.env` ფაილი `.env.example`-ის მიხედვით. მიუთითეთ რვაციფრიანი `TEACHER_PIN` და შემთხვევითი, მინიმუმ 32-სიმბოლოიანი `SESSION_SECRET`.

```sh
npm run check
npm start
```

ბრაუზერში გახსენით `http://localhost:3000`. ონლაინ გაშვებისას გამოიყენეთ HTTPS. Node.js-ის სერვერი რესურსებს `.istoria-media/` საქაღალდეში ინახავს. სხვა საცავის მისამართი შეგიძლიათ მიუთითოთ `ISTORIA_MEDIA_DIR`-ით. Worker-ისთვის `npm run build` ქმნის `dist/server/index.js`-ს. Worker-ს სჭირდება `BUCKET` სახელის R2 საცავი და გარემოს საიდუმლო მნიშვნელობები.

მთავარი ილუსტრაცია შექმნილია ImageGen-ით კავკასიონის ხეობის, ბრინჯაოს ცულისა და თიხის ჭურჭლის მოტივებით. შრიფტების ლიცენზიაა `public/assets/font-license.txt`-ში.
