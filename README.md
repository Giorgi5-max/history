# ისტორია · VII კლასი

საქართველოსა და მსოფლიოს ისტორიის ორი სახელმძღვანელოს პირველი ნაწილის სასწავლო ვებაპი. მასში გაერთიანებულია 38 პარაგრაფის ადაპტირებული ტექსტი, ავტომატური რეზიუმე და 760 სავარჯიშო შეკითხვა.

## გაშვება

საჭიროა Node.js 22 ან უფრო ახალი ვერსია. შექმენით `.env` ფაილი `.env.example`-ის მიხედვით. მიუთითეთ რვაციფრიანი `TEACHER_PIN` და მინიმუმ 32 სიმბოლოს შემთხვევითი `SESSION_SECRET`. გარემოს ფაილი გიტში არ შეიტანოთ.

```sh
npm run check
npm start
```

ბრაუზერში გახსენით `http://localhost:3000`. პორტი შეიძლება შეიცვალოს `PORT`-ით. ონლაინ გაშვებისას გამოიყენეთ HTTPS. Node.js-ის სერვერი რესურსებს `.istoria-media/` საქაღალდეში ინახავს. სხვა საცავის მისამართის მითითება შეიძლება `ISTORIA_MEDIA_DIR`-ით. ონლაინ Worker-ისთვის `npm run build` ქმნის `dist/server/index.js`-ს. Worker-ს სჭირდება `BUCKET` სახელის R2 საცავი და ზემოთ მითითებული ორი გარემოს საიდუმლო მნიშვნელობა.

## გამოყენება

- მასწავლებლის პანელში შეიყვანეთ პინი, აირჩიეთ სახელმძღვანელო და პარაგრაფი, შემდეგ ატვირთეთ ვიდეო, გაკვეთილის აუდიოჩანაწერი ან პოდკასტი. ვიდეოს რეკომენდებული ხანგრძლივობა 3–4 წუთია. MP4 ვიდეოს და MP3 ან M4A აუდიოს დაკვრა ბევრ ბრაუზერშია შესაძლებელი.
- ატვირთული ფაილები იხსნება იმავე პარაგრაფის ჩანართებიდან. აუდიოჩანაწერის დამატებამდე ტექსტის ავტომატური გახმოვანება მოწყობილობაზე არსებულ ქართულ სინთეზურ ხმას იყენებს.
- მოსწავლის ქვიზის პასუხები და საუკეთესო ქულები მის ბრაუზერში ინახება. ატვირთული მასალა სერვერზე ინახება და აპის სხვა მომხმარებლებისთვისაც ხელმისაწვდომია.
- გაკვეთილების ტექსტები და შეკითხვები `content/` საქაღალდეშია. წიგნების სარჩევი და გვერდების მითითებებია `public/catalog.js`-ში.

მთავარი ილუსტრაცია შექმნილია ImageGen-ით კავკასიონის ხეობის, ბრინჯაოს ცულისა და თიხის ჭურჭლის მოტივებით. შრიფტების ლიცენზიაა `public/assets/font-license.txt`-ში.
