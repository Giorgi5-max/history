# დროის მოგზაური — საქართველოს ისტორია VII

[აპლიკაციის გახსნა](https://drois-mogzauri-history-vii.giorgi-gorjeladze-1.chatgpt.site)

ერთი VII კლასის ქართულენოვანი სასწავლო აპლიკაცია: 6 თავი, 25 პარაგრაფი, 125 შეკითხვა, ოთხი თამაში და მასწავლებლის პანელი.

## მასწავლებლის პირველი შესვლა

1. გახსენით აპლიკაცია და აირჩიეთ „შესვლა“ → „მასწავლებელი“.
2. პირველად აირჩიეთ „მფლობელის ანგარიშით შესვლა“. მფლობელის ელფოსტა სერვერზე `OWNER_EMAIL`-ით განისაზღვრება.
3. შექმენით თქვენი პაროლი, მინიმუმ 12 სიმბოლოთი. ეს ანგარიში მხოლოდ ერთხელ იქმნება.
4. პანელის „მოსწავლეები“ ჩანართში ჩაწერეთ სახელები, თითოეული ახალ სტრიქონზე. ჩამოტვირთეთ შექმნილი პირადი კოდები და თითოეულ მოსწავლეს თავისი კოდი მიეცით.
5. „მიმოხილვიდან“ აირჩიეთ მიმდინარე გაკვეთილი და დანიშნეთ დავალება. ვადა თბილისის დროით მიეთითება.
6. „გაკვეთილებში“ თითოეულ პარაგრაფს აქვს ვიდეოს დამატების, ტექსტისა და შეკითხვების შესწორებისა და მოსწავლის ხედის გახსნის ღილაკები.

ტელეფონზე მასწავლებლის პანელი ხელმისაწვდომია ზედა ზოლში ანგარიშის ღილაკიდან. ანიმაციების გამორთვა პარამეტრების ღილაკით შეიძლება.

## მოსწავლის გზა

საკუთარი კოდით შესვლა → გაკვეთილი → მოკლე ახსნა → მასწავლებლის ვიდეო → სავარჯიშო ან თამაში → ქვიზი → შედეგი.

გაკვეთილის გახსნა ათვისებად არ ითვლება. სრული ქვიზის მინიმუმ 80%-ით შესრულება გაკვეთილს გავლილად ნიშნავს. შენახულია საუკეთესო შედეგი, დასრულებული მცდელობები და ბოლო მცდელობის გასამეორებელი შეკითხვები. ხელახალი შესვლისას, სხვა მოწყობილობაზეც, იგივე ანგარიშის პროგრესი აღდგება.

ქვიზის სწორი პასუხები წინასწარ არ იგზავნება მოსწავლის ბრაუზერში. პასუხს სერვერი ამოწმებს და მხოლოდ გაგზავნის შემდეგ აბრუნებს განმარტებას.

## ვიდეოები და საერთო მონაცემები

- MP4-ის პირდაპირი ატვირთვა — მაქსიმუმ 100 მბ თითო ვიდეოზე; დიდი ვიდეოსთვის გამოიყენეთ YouTube-ის ბმული.
- YouTube-ის ჩვეულებრივი, მოკლე და Shorts ბმულები.
- წინასწარი ნახვა, სათაურისა და აღწერის შეცვლა, ჩანაცვლება და წაშლა.
- MP4 ფაილები R2 საცავში ინახება. HTTP Range მოთხოვნები გადახვევას უზრუნველყოფს.
- ვიდეოს ნახვა მოქმედი ანგარიშით არის შესაძლებელი. ავტომატური დაკვრა გამორთულია.
- საერთო ტექსტი, დავალება, ვიდეოს მონაცემები, ანგარიშები და შედეგები D1-ში ინახება.
- მოსწავლისა და მასწავლებლის უფლებები ყველა შესაბამის მოთხოვნაზე სერვერზე მოწმდება.
- საერთო მონაცემები 45 წამში ერთხელ და გვერდზე დაბრუნებისას ახლდება.
- პირადი კოდები ჰეშირებულია; შექმნისას ისინი ერთხელ ჩანს. მასწავლებელს ახალი კოდის გაცემა შეუძლია.

## წიგნი და ისტორიული სიზუსტე

ჯაბა სამუშია, გიორგი სოსიაშვილი, ლერი თავაძე. „საქართველოს ისტორია 7“, მოსწავლის წიგნი, პირველი ნაწილი. საქართველოს განათლების, მეცნიერებისა და ახალგაზრდობის სამინისტრო, 2026. ISBN 978-9941-8-8928-8.

შენარჩუნებულია 6 თავი, 25 პარაგრაფის სათაურები და რიგი. ტექსტი ადაპტირებულია მოკლე ნაწილებად. თითო გაკვეთილს აქვს ხუთი მთავარი აზრი, ტერმინები, სავარჯიშო და ხუთი ოთხპასუხიანი შეკითხვა. მასწავლებელს ქვიზის გაზრდა ათ შეკითხვამდე შეუძლია.

მითები და ვარაუდები მონიშნულია. განსაკუთრებით გამოყოფილია დმანისის ჰომინინების კლასიფიკაცია, ეთნოგენეზის რეკონსტრუქცია, ალექსანდრეს სიკვდილის მიზეზი, ფარნავაზის შესახებ მატიანის ტრადიცია და წიგნის შიდა წინააღმდეგობები. გაურკვეველი საერთაშორისო ორგანიზაციის სახელწოდება ქვიზში არ არის გამოყენებული. ილუსტრაციების ნაწილი წიგნში თანამედროვე რეკონსტრუქციადაა წარმოდგენილი.

წიგნის გამოსახულებების საავტორო უფლებები თავდაპირველ მფლობელებს ეკუთვნით. ორიგინალი სრული PDF რეპოზიტორიაში არ არის შეტანილი. ქართული შრიფტია Noto Sans Georgian; ლიცენზია `public/assets/font-license.txt`-შია.

## ტექნიკური გაშვება

საჭიროა Node.js 24 ან ახალი და npm. გამოყენებულია Vinext/React, Cloudflare Workers, D1 და R2. წარმოების მონაცემები კოდის რეპოზიტორიაში არ ინახება.

```sh
npm ci
npm run check
npm run build
npm test
```

`npm test` ქმნის დროებით იზოლირებულ D1/R2 გარემოს და ამოწმებს ავტორიზაციას, მოსწავლეთა გამიჯვნას, ქვიზის სერვერულ შეფასებას, პროგრესის აღდგენას, მასწავლებლის ცვლილებების გავრცელებას, MP4-ის ატვირთვასა და Range დაკვრას, YouTube-ის ბმულებს, მეტამონაცემის ცვლილებას და ვიდეოს წაშლას.

ადგილობრივი ინტერფეისისთვის `.dev.vars`-ში მიუთითეთ `OWNER_EMAIL`. პირველ გაშვებამდე სუფთა ადგილობრივ D1-ში გამოიყენეთ `drizzle/`-ის SQL ფაილები თანმიმდევრობით. უკვე გამოყენებული მიგრაცია მეორედ არ გაუშვათ. შემდეგ გაუშვით `npm run dev`. გამოქვეყნებისას პლატფორმა წარმოების მიგრაციებს იყენებს; ადგილობრივი სატესტო ბაზა წარმოებაში არ გადადის.

მასპინძლობის კონფიგურაცია `.openai/hosting.json`-შია: `DB` და `BUCKET`. წარმოების `OWNER_EMAIL` გარემოს ცვლადით მიეთითება. მასწავლებლის პაროლი პირველად თვითონ მფლობელმა უნდა შექმნას. წინასწარ გაწერილი საერთო პაროლი ან მოსწავლის კოდი არ არსებობს.
